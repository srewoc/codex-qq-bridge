# Security policy

Please report vulnerabilities privately through GitHub Security Advisories. Do not open a public issue containing credentials, owner OpenIDs, transcripts, screenshots, socket paths, or hook payloads.

The bridge intentionally controls a local terminal. A compromised QQ Bot owner account or local account can therefore act with the same authority as the bound terminal session. Use a dedicated official bot, keep credentials private, review Hook changes, and bind only the session you intend to expose.

Supported security updates currently target the latest `main` branch and the latest tagged release.
